# Tutor+

**Приложение для частных репетиторов, преподавателей, коучей, психологов и тренеров** — единый инструмент для расписания, учёта учеников/клиентов, финансов, аналитики и напоминаний. Интерфейс на русском, светлая и тёмная темы.

> 🚧 **В активной разработке.** Реализованы **фазы 0–3 + UI-v2** (выравнивание по спеке v2.1, 18 слайсов): ядро домена (Ученики/Клиенты · Расписание с сериями · «Сегодня»), **Финансы** (сводка из трёх, операции, ожидаемые платежи, погашение долга), **Аналитика** (Обзор · Динамика · Задолженности, экспорт отчёта), **Уведомления** (лента, деталь, настройки), **Настройки** (профиль, темы День/Вечер/Авто, настройка главной), auth-флоу (вход · восстановление · мастер регистрации, против стаба до Фазы 4) — всё офлайн на WatermelonDB (схема v11) с dual-mode. **[Живое веб-превью →](https://kengston.github.io/tutor-plus-app/)**

## Идея

Частные практики теряют время на организацию расписания, учёт оплат и напоминания, а единого простого инструмента нет. Tutor+ закрывает весь операционный контур в одном мобильном приложении.

Ключевая механика — **dual-mode**: тип практики выбирается в профиле и меняет терминологию во всём приложении:
- режим **«Ученик»** — урок, предмет, ставка за урок (репетиторы, подготовка к ЕГЭ/IELTS/TOEFL);
- режим **«Клиент»** — встреча, направление, ставка за встречу (коучи, психологи, тренеры).

## Возможности

- **Сегодня** — «Ваш день» с прогрессом, ближайший урок с «Подключиться», далее по дню, карточка «Завтра», быстрые действия.
- **Расписание** — календарь с цветами учеников и список-таймлайн со свободными окнами; серии занятий (повторяющиеся слоты, отмена/перенос «только это / это и следующие / всю серию»); поиск и фильтр из шапки.
- **Ученики/Клиенты** — карточки со «следующее…», фильтры-чипы, поиск и сортировка из шапки, профиль с историей, заметками и быстрой связью.
- **Финансы** — сводка из трёх (получено / ожидается / задолженность), операции, ожидаемые платежи, погашение долга, периоды, поиск и фильтр из шапки.
- **Аналитика** — Обзор (структура дохода в 3 разрезах, сравнение периодов, «Выводы»), Динамика (селектор метрики, график с наложением периодов), Задолженности (aging «По сроку», «Требуют внимания»), экспорт отчёта с предпросмотром.
- **Уведомления** — производная лента (напоминания об уроках, оплаты, изменения), вкладки и фильтр, деталь с действиями, настройки с мастер-переключателем.
- **Настройки** — профиль, режим «Ученик ⇄ Клиент», рабочие дни, темы **День / Вечер / Авто** (по часам 19:00–7:00), цвета в расписании, настройка главной.
- **Вход и регистрация** — email/телефон + пароль, восстановление кодом, мастер регистрации «Шаг 1 из 5» с дефолтами (пока против локального стаба; сервер — Фаза 4).

## Технологии

- **Клиент:** [Expo](https://expo.dev/) (React Native + TypeScript) — единый код на **web · Android · iOS**.
- **Бэкенд:** [Supabase](https://supabase.com/) (PostgreSQL + Auth + Storage).
- **Офлайн-first:** [WatermelonDB](https://watermelondb.dev/) — локальное хранилище и синхронизация.
